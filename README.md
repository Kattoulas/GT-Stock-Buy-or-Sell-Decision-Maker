I created a GT model, inputting simple data on stocks and indexes such as EPS, PE ratio Forward PE's to help a trader or investor decide whether to buy, sell or hold.
There are two sides in the GT model, buyer and seller. Buyer can buy, hold or sell his position. Seller can short, hold or sell his position.
I calculated the expected value of a stock for a stock, given probabilities that can be input into the model. I also modelled a short squeeze and put some basic things in the calculation to make it more realistic.
This is the first model I have made so it is quite simple and not very thorough, with likely many holes in it but it was a fun first project.
